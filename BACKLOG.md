## Confirmed presentation decisions

- Home · About · Projects · Contact navigation.
- Approximately 820 px reading width with academic/editorial typography and restrained green accent.
- All project cards on Home; two columns on desktop and one on mobile.
- Projects page uses a larger, roomier version of the card grid.
- Project cards show image + project title only.
- Full project pages preserve image aspect ratio and use a contained hero image rather than forced cropping.
- Project pages use OTHER only when a PDF report is already confidently matched to that project.
- OTHER contains a separate 3–4 paragraph report summary, `View PDF Report ↗`, and relevant supporting visuals.
- Images are self-hosted in this repository rather than hotlinked from Google Sites.
- Oversized JPEGs are automatically resized to a maximum 1600 px dimension and recompressed for web delivery.
- Missing images fall back to a visible `Image unavailable` component instead of a broken-image icon.
- A public print-friendly CV is available from Contact without requiring Google authentication. The original Drive PDF remains a secondary source.
